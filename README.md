# homebrew-meepo

Homebrew tap for [Meepo](https://github.com/Azamatfg/meepo) — one window for all your Claude Code sessions.

```bash
brew tap azamatfg/meepo
brew trust azamatfg/meepo     # newer Homebrew asks once for third-party taps
brew install --cask meepo
```

Upgrade with `brew upgrade --cask meepo`.
